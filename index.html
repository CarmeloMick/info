GitHub 獨立設定檔 (`my-settings.json`) 儲存中心

將「程式介面 `index.html`」與「你的個人資料 `my-settings.json`」完全分開，以後升 Version 永不洗資料！

1 📂 雙檔案分離架構：喺 GitHub 放一個獨立 `my-settings.json`（最推薦！）
自動讀取 ./my-settings.json

💡 點解咁做之後 Update Version 永遠唔會唔見嘢？

你個 GitHub Repo 入面只需要放 2 個檔案：

  • index.html：純粹係玄關版嘅畫面同新功能（日後有新 Version，你只需要替換 `index.html`）。
  • my-settings.json：專門儲存你嘅巴士小巴路線、路線組合、玄關留言、本週重要事項、地區同主題。`index.html` 一打開就會自動讀取同一個資料夾入面嘅 ./my-settings.json！
2 ⚡ 進階全自動：連接 GitHub API（喺 iPad 改留言／事項自動寫入 GitHub！）
支援雙向直連

如果你喺玄關部 iPad 直接新增「本週重要事項」、改「玄關留言」或者加減「巴士路線」，唔想每次手動下載檔案放上 GitHub，可以填寫你個 GitHub Repo 同 Token（去 GitHub ➔ Settings ➔ Developer settings ➔ Personal access tokens 開一個有 Contents: Read & Write 權限嘅 Token）。
連接後，你喺網頁改任何路線、留言或事項，都會直接自動寫入你 GitHub Repo 入面嘅 `my-settings.json`！

💡 即使唔填 Token，只要將 `my-settings.json` 放喺同一個 GitHub Repo，每次打開網頁都會自動讀取。
